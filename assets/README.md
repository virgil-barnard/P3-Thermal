# Repository Assets

Tracked media for documentation and examples belongs here.

- `videos/learned-preview-comparison.gif` is a screen recording of the local
  native-versus-learned viewer.
- `images/synthetic-triangle-observed.png` is a native 256x192 synthetic
  observation.
- `images/synthetic-triangle-acquisition-4x.png` is its 4x acquisition-space
  simulator reference.
- `images/synthetic-triangle-ideal-4x.png` is its 4x instantaneous ideal
  simulator reference.

The synthetic examples are from the assumed-camera calibration lab, not P3
measurements or evidence of real-scene super-resolution. Keep generated corpora,
training runs, recordings, and large raw media out of this directory.
