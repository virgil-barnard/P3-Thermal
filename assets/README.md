# Repository Assets

Tracked media for documentation and examples belongs here.

- `videos/learned-preview-comparison.gif` is a screen recording of the local
  native-versus-learned viewer.
- `images/synthetic-four-bars-observed.png` is a native 256x192 synthetic
  observation.
- `images/synthetic-four-bars-acquisition-4x.png` is its 4x acquisition-space
  simulator reference.
- `images/synthetic-four-bars-ideal-4x.png` is its 4x instantaneous ideal
  simulator reference.
- `images/synthetic-fiducial-grid-{observed,acquisition-4x,ideal-4x}.png` are
  matching frame-zero references from fiducial-grid view 0.
- `images/synthetic-challenge-occlusion-{observed,acquisition-4x,ideal-4x}.png`
  are matching frame-zero references from the occlusion challenge scenario.

The synthetic examples are from the assumed-camera calibration lab, not P3
measurements or evidence of real-scene super-resolution. Keep generated corpora,
training runs, recordings, and large raw media out of this directory.
